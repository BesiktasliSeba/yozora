# logos

the marks of the search engines as 256 pixel pictures (`google.png`, `duckduckgo.png`, `yandex.png`), trimmed to their outline and set on a square.
the marks belong to their owners and appear only to name the search engine. `tools/make_ui_icons.py` writes them as 96 pixel colored pictures `app/icons/ui/yz-logo-<file>.png`.
